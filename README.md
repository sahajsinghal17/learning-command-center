# Learning Command Center

**A centralized learning operating system for managing multiple rigorous tracks, tasks, and deadlines.**

## Problem
Serious learners often pursue several subjects simultaneously (e.g., Competitive Programming, University Coursework, Full Stack Development). This leads to a fragmented workflow across notes, calendars, and problem platforms, resulting in missed deadlines and lost progress.

## Solution
Learning Command Center is a unified dashboard that tracks curricula, tasks, scheduled contests, and strict deadlines in one place. It answers the core question: *What should I work on next, and what is due today?*

## Tech Stack
* **Frontend:** Next.js, TypeScript, Tailwind CSS
* **Backend:** FastAPI, Python
* **Database:** PostgreSQL (with SQLAlchemy and Alembic)

## Project Structure
```text
learning-command-center/
```
